# DartLink WebSite

Site vitrine pour présenter DartLink, le système intelligent de comptage de points pour les parties de fléchettes.

## Pages
- `index.html` : présentation du produit, démonstration des fonctionnalités et témoignages.
- `shop.html` : offres commerciales et formules adaptées aux particuliers, clubs et tournois.
- `support.html` : assistance, FAQ et formulaire de contact.

## Style
Une feuille de style globale est disponible dans `assets/css/style.css` avec un design sombre et moderne pensé pour l'univers e-sport.

## Utilisation
Ouvrez l'une des pages HTML dans votre navigateur pour prévisualiser le site. Les formulaires sont statiques et ne déclenchent pas d'envoi d'e-mail sans intégration supplémentaire.
